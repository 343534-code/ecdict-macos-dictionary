# 最新查询页面 · v1.2.1

![三指查询：首屏与更多展开的界面示意动画](images/lookup-demo-v121.gif)

**界面示意动画，非系统录屏。** 动画展示经过实机验证的内容层级，不模拟触控板硬件手势。系统实际浮窗尺寸和“更多”位置可能不同。

## 首屏

单词、IPA、Oxford/Collins 评级及各词性的第一条原始释义。首条释义沿用源数据顺序，不等于经过 AI 选出的最常见含义。

## 点击更多

显示后续释义、专业领域标签、词形变化链接、考试大纲和 BNC/COCA 词频。词典 App 完整页面仍按词性分组。
